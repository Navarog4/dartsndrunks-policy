2. Application concernée

La présente Politique de Confidentialité s'applique à l'application mobile « DartsNDrunks » (ci-après « l'Application »), publiée sur le Google Play Store (Android, identifiant com.dartsndrunks.game).

L'Application est un jeu de fléchettes à gages (usage adulte, rattaché à la consommation d'alcool) permettant de gérer des parties, des scores, des pénalités et des modes de jeu gratuits et premium.

3. Principes directeurs

  • Stockage local : Les données de jeu (profils, scores, historique, préférences) sont stockées exclusivement sur votre appareil dans une base de données SQLite embarquée. Aucune de ces données n'est transmise à l'Éditeur (qui n'exploite aucun serveur).
  • Minimisation : Nous ne traitons que les données strictement nécessaires au fonctionnement du jeu et à la diffusion de publicités.
  • Transparence : Nous déclarons ci-dessous, de manière exhaustive, les données collectées, leur finalité, leur base légale et leur durée de conservation.
  • Consentement publicitaire : Les publicités personnalisées ne sont affichées qu'avec votre consentement exprès, recueilli via le bandeau de consentement Google (UMP) conformément au RGPD.
  • Contrôle utilisateur : Vous supprimez vos données de jeu directement dans l'Application.

6. Publicité — détail du fonctionnement

6.1 Types de publicités

  • Interstitielles : affichées à des moments précis de l'Application (au démarrage et/ou entre les parties), selon la configuration par défaut et les préférences de l'utilisateur.

6.2 Publicités personnalisées vs non personnalisées

  • Personnalisées : basées sur l'identifiant publicitaire, les centres d'intérêt et le comportement de navigation. Nécessitent votre consentement (bandeau UMP).
  • Non personnalisées : basées exclusivement sur le contexte (type de contenu, heure, langue, localisation approximative par IP). Ne nécessitent pas de consentement.

6.3 Absence de consentement

Si vous refusez la personnalisation, l'Application reste totalement fonctionnelle : seules des publicités non personnalisées sont diffusées. Les modes de jeu, les scores et les achats intégrés ne sont pas affectés.

10. Sécurité

  • Données locales : stockées dans le sandbox sécurisé de l'Application (Android app sandbox), chiffrement des accès par Android Keystore pour les éventuelles clés.
  • Réseau : seules les connexions vers les serveurs Google (publicité, achats) et Expo (mises à jour) sont établies, chiffrées en TLS.
  • Authentification des achats : validation côté Play Store (Google), anti-fraude.
  • Code : la version distribuée utilise Hermes bytecode ; les mises à jour sont signées (EAS).
